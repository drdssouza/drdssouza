## 🧠 Sobre mim

Engenheiro de Inteligência Artificial com experiência no desenvolvimento de soluções de **IA aplicada e Generative AI** para grandes empresas dos setores:

- Financeiro  
- Seguros  
- Jurídico  
- Educacional  
- Tecnologia  

Atualmente atuo na **Compass UOL** como consultor de IA, desenvolvendo sistemas baseados em **LLMs (Claude, AWS Bedrock)** com foco em:

- Automação de processos complexos  
- Análise de dados  
- Integração de serviços AWS
